# Vendored copy of the patched libfprint tree this kit is built from.
#
# Source: ~/verimark/libfprint on the development machine (a libfprint
# master snapshot, version 1.94.100, plus the working realtek driver for
# the Kensington VeriMark 047d:8228). The proven, actually-tested build
# lives there; this copy exists so the kit can rebuild anywhere.
#
# Deviations from that tree (for a slim vendored copy):
#   - tests/, examples/, doc/, demo/ directories are not vendored;
#     meson.build guards subdir('tests') and subdir('examples') behind
#     new boolean options (see meson_options.txt) and meson_options.txt
#     gained those options.
#   - The one test header libfprint core needs (fpi-test-emulation.h,
#     normally generated by meson into tests/) is vendored as a static
#     placeholder in tests/fpi-test-emulation.h.
#   - .git is not vendored.
#
# Build (any distro):
#   meson setup builddir -Dtests=false -Dexamples=false -Ddoc=false
#   meson compile -C builddir
# Result: libfprint/builddir/libfprint/libfprint-2.so.2.0.0
#
# The driver of interest is libfprint/drivers/realtek/realtek.{c,h}.
# Protocol and debugging background: ../docs/FINDINGS.md.
